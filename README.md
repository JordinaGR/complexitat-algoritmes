[CAT]

Dins de la carpeta v2 hi ha quatre fitxers .csv amb totes les dades obtingudes del programa algs.cpp. La resta de fitxers .py llegeixen, netejen les dades i creen els gràfics.

Eina d'anàlisi de rendiment que combina la velocitat d'execució de **C++** amb la capacitat d'anàlisi de dades de **Python**. Permet mesurar i analitzar empíricament el temps d'execució d'algoritmes d'ordenació per contrastar els resultats pràctics amb la notació de Landau ($\mathcal{O}$).

> **Context:** Projecte desenvolupat el 2020 com a mòdul de benchmarking per al Treball de Recerca (TDR) de Batxillerat.

1. **Implementació en C++:** Codi optimitzat en C++ per a l'execució d'alta velocitat dels algoritmes d'ordenació i la mesura precisa de temps.
2. **Exportació de dades a CSV:** Emmagatzematge automàtic de les mètriques i resultats de les proves en fitxers `.csv`.
3. **Anàlisi i gràfics en Python:** Processament de les dades de rendiment i generació de gràfics comparatius mitjançant scripts de Python.

---

## Tecnologies utilitzades

* **Motor d'execució:** C++ (alta velocitat i precisió de temps)
* **Anàlisi i Visualització:** Python 3 (Pandas, Matplotlib)

# Empirical Complexity Analysis of Sorting Algorithms

Inside the `v2` folder, there are four `.csv` files containing all the data generated by the `algs.cpp` program. The remaining `.py` files read and clean the data, and generate the corresponding charts.

Performance benchmarking tool that combines high-speed execution in **C++** with data analysis capabilities in **Python**. It measures and analyzes algorithm execution times empirically to contrast real-world performance against theoretical Big O notation ($\mathcal{O}$).

> **Context:** Project developed in 2020 as a benchmarking module for a high school research project (*Treball de Recerca / TDR*).

---

## Key Features

1. **C++ Implementation:** High-performance C++ code for fast execution and high-precision timing of sorting algorithms.
2. **CSV Data Export:** Automated logging of benchmark results and timing metrics into `.csv` files.
3. **Python Data Analysis & Plotting:** Data processing and chart generation scripts built with Python to compare theoretical vs. empirical complexity.

---

## Built With

* **Execution Engine:** C++ (high speed and timing precision)
* **Analysis & Visualization:** Python 3 (Pandas, Matplotlib)
* **Data Format:** CSV
